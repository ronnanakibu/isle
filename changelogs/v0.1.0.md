# Release v0.1.0 — Initial Pre-Release: Dynamic Island & Living Desktop Companion

### Highlights

- **Clean Viewport & Daily Driver Mode**:
  - Isle mounts cleanly flush against the top display bezel ($y = 0$) with a clean transparent backdrop, ready for everyday desktop usage.
  - The developer simulator bar is hidden by default in production mode and can be toggled on/off at any time using the global shortcut `Ctrl + Shift + D`.

- **Dynamic Breathing Lyric Pill**:
  - When music is playing and Isle is collapsed, the compact pill automatically expands and contracts (`clamp(210px, textWidth + 84px, 480px)`) to hug active lyric lines in real time.
  - Features smooth spring physics transitions: outgoing lyrics slide up and fade away, while incoming lyrics glide smoothly into place from below.
  - During instrumental breaks lasting longer than 3.5 seconds, the pill smoothly contracts back to its minimal resting width (~200px).

- **Shiba Mascot & ThinkPad F4 Hardware Mic Privacy**:
  - Procedural animated Shiba companion with live gaze tracking, automatic procedural blinking, and expressive emotional ear wiggles.
  - When the microphone is muted (via UI or hardware ThinkPad `F4` key), Shiba's mouth is covered with a cute white tape cross `( · 🗙 · )` to visually guarantee audio privacy.
  - Dynamic privacy indicators for microphone and camera appear only when an application is accessing sensors, shifting neighboring elements naturally, and sliding away when access finishes.

- **Consolidated 7-Tab Productivity Suite**:
  - The bottom of the expanded card displays subtle white pagination dots by default.
  - Hovering over the dots smoothly reveals a floating frosted glass icon dock providing instant navigation across 7 consolidated activities:
    1. 🎵 **Media**: Fluid media controller with karaoke synced lyrics side pane and strict scroll-wheel isolation.
    2. ⏱️ **Focus**: 25/5 Pomodoro timer with automatic break transitions and singing bowl alerts.
    3. 💧 **Hydration**: Daily water intake logger with midnight auto-rollover and streak retention.
    4. 📝 **Tasks**: Quick categorized checklist with priority tags.
    5. 📁 **Shelf & Clipboard**: Unified file staging, screenshot organizer, and clipboard history.
    6. ⚡ **Hardware**: Telemetry indicators for processor, memory, graphics, and network load.
    7. 🧘 **Zen Breathing**: Visual 4-4-4-4 Box Breathing relaxation guide.
    *(and Settings access)*

- **Claude Code & CLI Agent Live Monitor**:
  - Replaces generic robot icons with the official Anthropic Spark / Starburst logo for Claude Code and clean Terminal icons for CLI agents.
  - Provides real-time action headlines, interactive one-click `Approve` / `Reject` buttons for CLI permissions, and pass/fail build toasts with instant terminal focus.

- **4-Theme Architecture**:
  - Universal theme switcher offering **System Auto**, **OLED Dark**, **Pearl Light**, and **Liquid Glass (Mica)**.
  - Includes real-time multi-pass backdrop blur filtering and a performance advisory badge for the Liquid Glass mode in Settings.

- **Battery Action Animations & Screenshot Integration**:
  - Charging connected pulse with an authentic battery sweep fill from 0% to current percentage.
  - Low battery warning alerts (<20%) triggering Shiba's sympathetic puppy expression.
  - Screenshot capture staging JSON path metadata to the Shelf store with a configurable *"Hide Isle during Screenshots (PrtSc)"* toggle in Settings.
