# Release v1.0.0 — Official Stable Release: Pure Native Windows Dynamic Island

### Highlights

- **Windows System Tray Integration & Quick Settings**:
  - Isle now lives comfortably in the Windows Taskbar Notification Area (System Tray).
  - Right-clicking the tray icon reveals a quick context menu to open Settings, switch interaction modes, toggle the island, or exit cleanly.
  - Accessing Settings no longer expands a giant card over your browser tabs; the island remains compact and focused on your screen bezel.

- **Interaction Modes: Hover vs. Click with Anti-Swoop Protection**:
  - **Click to Expand (Default Safe Mode)**: Prevents accidental opening when quickly moving the cursor across the top of your monitor to close browser tabs or type into the address bar.
  - **Hover to Expand (Fluid Mode)**: Features an intelligent 200ms anti-swoop debounce delay. Fast cursor swipes are ignored, and the island only unfolds smoothly when your cursor intentionally rests on the pill, with a 260ms grace period before closing.

- **100% Real Windows OS Integration (Zero Mockups)**:
  - **Real Battery Monitoring**: Live, accurate battery percentage and charging status read directly from your laptop hardware.
  - **Real Hardware Telemetry**: True physical RAM and processor load gauges without simulated numbers or artificial jitter.
  - **Live Media & Synced Lyrics**: Directly communicates with Windows media playback (Spotify, Apple Music, YouTube Music, and media players). When no song is active, the island rests in a clean idle state; when music plays, live synced lyrics stream in real time.
  - **Live Clipboard History**: Automatically tracks text and file paths copied across Windows for one-click access.
  - **Microphone Privacy Feedback**: Real-time microphone mute status detection. When your mic is muted (including via ThinkPad F4 hardware key), Shiba's mouth is covered with a friendly white privacy tape cross `( · 🗙 · )`.

- **Pure Native Standalone Engine**:
  - Ground-up native Windows engine compiled into an ultra-compact standalone binary (~459 KB).
  - True zero-idle CPU architecture: uses 0.0% CPU when resting, springing to life only when active.
  - Minimal memory footprint (<15 MB RAM) with sub-50ms instant startup.
  - Per-pixel click pass-through: clicks outside the pill or expanded card pass straight through to background browser tabs, address bars, and desktop icons with zero lag.

- **Official Windows Installer Setup**:
  - Easy-to-use modern Windows setup installer.
  - Registers Isle officially in Windows Installed Apps & Settings.
  - Creates Start Menu and Desktop shortcuts, with an optional toggle to launch automatically on Windows startup.
  - Clean uninstaller for effortless removal.
