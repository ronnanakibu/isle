# Isle v1.0.0 — Apple Dynamic Island for Windows

## Highlights

### 🏝️ Apple Dynamic Island Design & Aesthetics
- **Continuous Squircle Curvature**: Recreated Apple's continuous squircle curvature with deep OLED true black body and subtle 1px specular glass rim lighting.
- **Adaptive Sizing**: Floats centered at the top of the primary display, transitioning smoothly between an unobtrusive compact pill (`205 × 36 pt`) and an expansive Live Activity card (`370 × 160 pt`).
- **Living Notch Mascot**: Interactive animated companion with procedural eye tracking following the cursor and natural blinking behavior.

### ⚡ Fluid 60 FPS Spring Animation
- **Apple Harmonic Physics**: Damped spring oscillator physics ($\omega = 16.0$, $\zeta = 0.72$) delivering Apple's fluid rubber-band bounce on mouse hover expansion and collapse.
- **Zero-Idle Efficiency**: Consumes 0.0% CPU when idle; animation timers activate strictly during dynamic transitions.

### 📱 5 Live Activity Pages
1. **Music Player**:
   - High-fidelity album artwork with vinyl groove styling.
   - Live 5-band dynamic audio equalizer visualizer.
   - Interactive playback scrubber bar with track timestamps.
   - Native Windows Media Key integration (`Play/Pause`, `Previous`, `Next`) controlling Spotify, Apple Music, and web players.
2. **Pomodoro Timer**:
   - Circular countdown progress ring.
   - Interval mode selector pills: Focus (25m), Short Break (5m), and Rest (15m).
   - Start, Pause, and Reset controls.
3. **Daily Hydration Tracker**:
   - Visual tumbler with animated liquid fill level.
   - Daily progress percentage counter.
   - One-click quick-log buttons (`+250 ml`, `+500 ml`, `Reset`).
4. **Reminders Checklist**:
   - Minimalist task list with interactive circular checkboxes.
   - Real-time completed count badge.
5. **Quick File Shelf**:
   - AirDrop style file cards with quick open shortcuts.
   - Fast access to workspace files and downloads.

### 👆 Intuitive Gestures & Navigation
- **Page Indicator Pill**: Apple-style pagination dots at the bottom of the card for 1-click page switching.
- **Click-Through Transparency**: Non-visible canvas areas pass mouse clicks directly to underlying desktop windows.
