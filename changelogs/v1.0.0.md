# Release v1.0.0 — Claude Code Live Agent Monitor, Authentic Nusa Parity, & Anti-Slop Overhaul

### Highlights
- **Claude Code & CLI Agent Live Monitor (Mission Control HUD)**:
  - Turned Isle into an intelligent Mission Control HUD for developers running Claude Code, Gemini CLI, and terminal coding agents.
  - Five expressive agent states with responsive Shiba mascot reactions:
    - **Standby / Idle**: Clean, resting desktop state when no CLI operations are underway.
    - **Thinking / Processing / Tool Execution**: Compact pill displays `[ 🤖 Claude Code: Editing window.rs... ]` with a subtle pulsing cyan aura, while Shiba puts on cute programmer glasses / HUD visor with a gentle thinking pulse.
    - **Waiting for Approval / Question**: Drops down an interactive notification pill `[ ⚠️ Claude Code: Approval Required · Run 'cargo test'? ]` with `[ Approve ]`, `[ Reject ]`, and `[ Focus Terminal ]` one-click actions.
    - **Task Complete / Build Passed**: Sleek emerald green toast `[ ✅ Claude Code: Build Passed · 8 files modified ]` paired with a cheerful Shiba celebration and ear bounce.
    - **Build Failed / Error**: Amber/red warning toast `[ ❌ Claude Code: Test Failed (Exit 1) ]` triggering Shiba's sympathetic, concerned puppy expression.
  - Comprehensive simulation controls in the developer bar to test all live agent activity states.

- **Visual Cleanup & Anti-Slop Overhaul**:
  - **Notch Mode Bezel Flush Silhouette**: Fixed the top-left boundary protrusion ("plek" glitch). In Notch mode, the silhouette mounts strictly flush ($y = 0$, `rounded-t-none`) against the physical monitor bezel, curving downwards with smooth bottom corners (`rounded-b-[22px]`) and zero leaking outer concave wings.
  - **Clean Apple Header & Balanced Grid**: Eliminated all artificial neon bullet dots, redundant settings gear icons, collapse chevrons, and search bars. Balanced 3-column layout featuring Shiba mascot on the left, clean icon-accompanied section pill in the center, and a dedicated Focus DND Moon toggle on the right.
  - **Authentic Lyrics Reveal Experience**: Removed branding tags and developer toggles. Media view defaults to clean, spacious playback controls (vinyl album art, marquee, transport, progress, volume). Clicking the lyrics toggle smoothly slides playback to the left half and reveals the synced lyrics pane on the right. When the mouse leaves the island, it collapses into the Live Breathing Lyric Ticker.

- **Scroll-Wheel Isolation**:
  - Complete scroll containment: scrolling mouse wheel inside the Lyrics box, Tasks checklist, Shelf file staging, or Clipboard history strictly scrolls container text vertically.
  - Card-level tab switching is automatically bypassed when the cursor is inside scrollable content, preventing accidental tab navigation.

- **Consolidated 7-Tab Productivity Suite**:
  - Pruned redundant tabs and merged File Shelf and Clipboard History into a unified **Quick Shelf & Clipboard** tab with a segmented top toggle (`[ Staged Files | Clipboard History ]`).
  - Focused 7-tab suite:
    - Tab 1: 🎵 **Media** (Playback + Synced Lyrics with side-by-side reveal)
    - Tab 2: ⏱️ **Focus** (Pomodoro Timer with phase progression)
    - Tab 3: 💧 **Hydration** (Water Tracker with midnight auto-rollover and streak count)
    - Tab 4: 📝 **Tasks** (Priority-coded reminders checklist)
    - Tab 5: 📁 **Shelf & Clipboard** (Unified file staging, screenshots, scrcpy companion, and clipboard history)
    - Tab 6: ⚡ **Hardware** (CPU, RAM, GPU, and network telemetry)
    - Tab 7: 🧘 **Zen Breathing** (4-4-4-4 Box Breathing visual guide)

- **Hardware Integrations & Event Mechanisms**:
  - **Screenshot Auto-Capture Hook**: Pressing `PrintScreen` (or using the simulator button) creates a JSON metadata entry in the Shelf store with zero physical image duplication, accompanied by a 2.5-second HUD toast and 1-click "Copy Path" and "Open".
  - **Peripheral & Wireless Devices Detection**: Added connection toasts for wireless earbuds (with left/right battery percentages), smartphones, and wireless printers.
  - **Authentic Nusa Battery Actions**: Green lightning pulse animation expanding outwards on charger connect accompanied by a happy Shiba ear bounce, power unplug indicator, golden glow at 100% battery, and low-battery warning toast (<20%) triggering Shiba's sad droopy-ear expression.
  - **ThinkPad F4 Mic Mute Visual State**: Hardware hotkey `F4` mutes the microphone and visually covers Shiba's mouth with a cute white tape cross `( · 🗙 · )`; clicking Shiba or pressing `F4` unmutes and restores the friendly smile.
